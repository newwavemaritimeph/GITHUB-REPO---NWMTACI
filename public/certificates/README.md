## Contents are unaltered

Per the implementation skill, these are published **unmodified**: no blur,
crop, or edit to any number, date, QR code, seal or stamp. The `.webp` files
are plain resized derivatives for the hero row; every link on the site opens
the original PNG.

That means the lower-left block on each document — reference number, date,
**the amount paid to MARINA (Php 169,630)** and the stamp-tax line — is
readable at full size. That is commercial information, and it is on a public
page only because the supplied instructions require the documents to be
unmodified. If that should not be public, the decision is to blur that block
on the published copies (the originals would stay untouched); say so and it is
a one-line change.
